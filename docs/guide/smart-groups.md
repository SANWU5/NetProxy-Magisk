# 智能分组

智能分组把全部订阅与本地配置中的节点按地区整理成分组，例如「香港」「日本」「美国」。
每个分组默认在组内自动选择延迟最低的节点，也可以在组内手动指定节点。

## 生成分组

在节点页点按「智能分组」进入分组页，首次使用点按「开始智能分组」，之后可以随时「重新智能分组」：

- 按国旗、中英文国名与城市名、国家与机场代码识别节点所属地区；
- 剩余流量、到期时间等提示性节点不参与分组；
- 无法识别地区的节点归入「其他」；常用地区排在前面，其余按节点数量排序，中国大陆与无法识别的节点排在最后。

智能分组只在手动触发时更新，订阅更新后不会自动重新分组，需要时再点一次「重新智能分组」。
重新分组时，地区分组的改名以及手动加入、移除的节点都会保留；自建分组不受影响。

## 使用分组

- 在分组列表中点按分组右侧的圆圈，或在分组内点按「使用这个分组」，节点页就改用这个分组。
  仪表盘显示分组名与它当前实际使用的节点。
- 点进分组：顶部是「自动选择」，下面是成员节点与延迟，点哪个用哪个，也可以改回自动选择。
  每个分组分别记住组内的选择；从未在组内选过节点时使用自动选择。
- 「全部测速」测试分组内的全部成员，连不上或超时的成员显示「失败」。
- 分组没有可用节点时，节点选择自动回退到原来的普通分组。

## 编辑与自建分组

- 可以修改分组名称和成员。成员按「来源分组 + 节点名」引用：订阅删掉某个节点只会让分组变小，不会影响核心启动；
  组内手动选择的节点不在分组中后，分组回到自动选择。
- 「新建自建分组」：自己勾选节点组成分组，例如把几个常用的低延迟节点放在一起，同样支持组内自动选择与手动选择。
- 删除分组后，正在使用它的节点选择或链式前置会改回原来的设置。

## 与链式代理配合

链式代理的前置可以指定为智能分组或自建分组；在链式页「选择前置」中勾选几个节点自动选择时，
会保存为自建分组「链式前置自选」。详见[链式代理](./chain-proxy#前置)。

## 数据位置

分组、组内选择与手动修改保存在模块的 `data/smart/groups.json`。
